What it is

A small self-hosted sync layer for Obsidian. Devices talk to Syncidian. Syncidian talks to GitHub. Your notes stay yours.

What it solves

Obsidian is local. Life is not. Syncidian gives every device a live copy, then a durable backup on the main branch of one GitHub repository.

How it works

1. Sign inGitHub, or email if you prefer.
2. Connect one repoInstall the GitHub App with read and write access.
3. SyncThe plugin talks to this server. The server commits to main.
