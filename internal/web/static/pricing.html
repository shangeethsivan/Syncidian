FAQ

What is the difference between hosted and self-host?

Hosted is $2/month on app.syncidian.com. We run the server. Self-host is free: you run the open-source server on your own machine or Railway.

How long is the trial?

14 days. After that, Polar checkout on app.syncidian.com. Trialing still lets you connect a repository.

What does GitHub login read?

Your GitHub profile and email so we can sign you in. No repository access at that step. Connecting a repo is a later, optional step after you subscribe.

What happens if I cancel?

You keep access until Polar marks the subscription revoked at the end of the paid period. There is no extra local grace clock.

Do I need Polar to sync devices?

No. Device sync works after waitlist and login. The paywall is only when you connect a GitHub repository.
